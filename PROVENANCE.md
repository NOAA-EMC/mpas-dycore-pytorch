# Provenance

Each generated package records its version, payload digest, file count, and data
policy in `RELEASES.json`. `SHA256SUMS` binds every distributed file.

The dynamics-core implementation is derived from MPAS-Atmosphere v8.3.1. It is
a modified work and is not the upstream MPAS-Atmosphere distribution. The
upstream copyright, conditions, and disclaimer are preserved in
`THIRD_PARTY_NOTICES.md`.

No scientific datasets, meshes, initial conditions, trajectories, model output,
or development material are bundled.
